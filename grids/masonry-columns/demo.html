Packed, or in order

A packed layout reads down each column, which is fine for a wall of pictures and wrong for anything sequential. The numbers below show it.

Packed, column order

Ordered, row order

  1. 01

    Across, not down.

  2. 02

    Second is beside first

    Which is what a reader, a screen reader and the tab key all expect.

  3. 03
  4. 04

    Two columns wide

    A column layout has no concept of this, which is another thing the packed version cannot do.

  6. 06
