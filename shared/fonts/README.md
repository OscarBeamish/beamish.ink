# Fonts

Latin subsets, variable weight 400–700, self-hosted so `demo.html` renders in the
real faces with no network and the recorder never captures a fallback.

- `jetbrains-mono-latin.woff2` — JetBrains Mono, © 2020 The JetBrains Mono Project
  Authors. SIL Open Font License 1.1.
- `archivo-latin.woff2` — Archivo, © 2016 The Archivo Project Authors.
  SIL Open Font License 1.1.

Both licences permit redistribution and bundling. Neither font is renamed or
modified; the files are the Google Fonts latin subsets unaltered.
